# CRM для салона красоты

API для управления записями клиентов, расписанием мастеров, каталогом услуг и историей посещений в небольшой бьюти-студии. Система исключает накладки в расписании мастеров, централизует клиентскую базу и обеспечивает мгновенную обработку онлайн-записей
